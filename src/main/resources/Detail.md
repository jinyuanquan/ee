# Detail

## 路径定位

- 当前目录：`src/main/resources`
- 上一级："src/main"
- 直接子目录数量：1
- 直接文件数量：1

## 这一层在做什么

这一层是运行时资源根目录，决定模组能否被游戏识别、能否显示正确文本。

## 这一层直接包含什么

### 子目录

- `bundles`：这一层保存国际化文本，是 UI 功能的一部分，而不是附属资源。

### 文件

- `mod.json`（667 B）：模组元数据；声明名称、版本、描述、最低游戏版本与入口类。

## 实现方式

`mod.json` 声明模组身份、入口类和版本；`bundles` 提供国际化文本。虽然文件不多，但它们都是模组加载和 UI 展示的硬前提。

## 与其他层级的关系

它向上被构建任务复制到 `build/resources/main`，向下在运行时被资源加载器和 bundle 系统读取。

## 补充观察

在小型模组里，资源层常被低估，但它其实同时承担“可加载”和“可本地化”两种基础能力。
