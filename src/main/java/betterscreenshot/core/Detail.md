## 这一层在做什么

这一层是项目的核心算法区，当前只有 `Screenshot.java`，但它承担了整张地图截图的实质工作。

## 这一层直接包含什么

### 子目录

- 当前没有子目录。

### 文件

- `Screenshot.java`（11.4 KB）：核心截图引擎；负责分块渲染、尺寸估算、状态恢复与 PNG 写出。

## 实现方式

代码会估算目标像素尺寸与分块数量，在纹理上限内复用同一个 `FrameBuffer` 分块渲染，再把各块 `Pixmap` 拼成完整大图，并在后台线程写出 PNG。它还会保存并恢复天气绘制、UI 禁用状态、相机、场景层级和裁剪区域，避免截图过程污染游戏正常渲染。

## 与其他层级的关系

它向上被功能层调用，向下只依赖 Arc/Mindustry 图形与 UI 基础设施，因此是纯引擎层。
